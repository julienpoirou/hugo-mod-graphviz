# Security policy

## Reporting a vulnerability
Please **do not** open a public issue.  
Contact: **julienpoirou@protonmail.com** (subject `[SECURITY]`).

Include:
- module version, OS, Hugo version, browser if relevant
- reproduction steps
- estimated impact

We acknowledge reports within 72 hours. We then assess impact, share a remediation plan within 7 days, and provide progress updates at least every 14 days until resolution.

## Coordinated disclosure
Please allow us reasonable time to investigate and release a fix before public disclosure. We will coordinate the disclosure timeline with the reporter and credit them in release notes only with their consent.

## Supported versions
- Latest release + previous (security patches).
